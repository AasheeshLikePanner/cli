## The things that will get flagged

**1. The sorting algorithm is a bubble sort.**

Look at your `sortByScoreAndTime`:

```go
for i := 0; i < len(entries); i++ {
    for j := i + 1; j < len(entries); j++ {
        ...
    }
}
```

That's O(n²). Go has `sort.Slice` built into the standard library. A senior Go engineer sees this and immediately knows either you don't know the stdlib or you didn't think about it. This is a one-line fix and it's the most visible code quality signal in the whole PR:

```go
sort.Slice(entries, func(i, j int) bool {
    if entries[i].Score != entries[j].Score {
        return entries[i].Score > entries[j].Score
    }
    return entries[i].Entry.CreatedAt.After(entries[j].Entry.CreatedAt)
})
```

Fix this before anything else.

**2. Lock retry is missing — this is a functional bug.**

Your `AppendEntries` calls `TryLock()` and if it fails, immediately returns an error. The early design called for 3 retries with 50ms backoff. Without it, when two agents commit simultaneously, one of them silently loses its prompt entry to the index. That's data loss. The `TestStore_ConcurrentWrites` test probably passes because it checks that the lock prevents corruption, not that both writes eventually succeed.

Add the retry:

```go
func (s *Store) AppendEntries(entries []Entry) error {
    lock := newLockFile(s.lockPath)
    
    var lockErr error
    for attempt := range 3 {
        lockErr = lock.TryLock()
        if lockErr == nil {
            break
        }
        time.Sleep(time.Duration(50*(attempt+1)) * time.Millisecond)
    }
    if lockErr != nil {
        return fmt.Errorf("acquiring lock after retries: %w", lockErr)
    }
    defer lock.Unlock()
    return s.appendEntriesLine(entries)
}
```

**3. Stale lock file on crash.**

Your lock behavior table says "lock file removed on next write attempt" — but your `TryLock` uses `O_CREATE|O_EXCL` which fails if the file exists. If the process crashes mid-write, the lock file stays forever and every subsequent write fails permanently. You need stale lock detection — check if the lock file is older than a reasonable threshold (say 30 seconds) and remove it:

```go
func (l *fileLock) TryLock() error {
    // Check for stale lock
    if info, err := os.Stat(l.path); err == nil {
        if time.Since(info.ModTime()) > 30*time.Second {
            _ = os.Remove(l.path) // stale, remove it
        }
    }
    f, err := os.OpenFile(l.path, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o600)
    if err != nil {
        return fmt.Errorf("lock held: %w", err)
    }
    l.file = f
    return nil
}
```
